# Screenshots

Drop the following PNG files in this folder so they render in the project README.

| Filename | Page | What to capture |
| --- | --- | --- |
| `overview.png` | `Overview.py` | KPI row + monthly revenue chart visible, sidebar date slider expanded |
| `rfm.png` | `pages/1_RFM_Analysis.py` | Bar chart + revenue donut + segment table |
| `seller_performance.png` | `pages/2_Seller_Performance.py` | Top sellers chart + revenue by state, with at least one state filtered |
| `cohort_retention.png` | `pages/3_Cohort_Retention.py` | Retention heatmap with cell labels visible |

Suggested viewport: **1440 × 900**, light theme, full-page (sidebar visible).

## How to capture

1. Run the app: `streamlit run app/Overview.py`
2. Open `http://localhost:8501` in Chrome
3. For each page, set the viewport (DevTools → Toggle device toolbar → 1440×900) and take a full-page screenshot (Cmd/Ctrl+Shift+P → "Capture full size screenshot")
4. Save the PNG in this folder using the names above
